# ¡Vamos! — учим латиноамериканский испанский

PWA-приложение для изучения испанского языка Латинской Америки: сначала — самые
употребительные слова, затем комбинаторный движок собирает из них максимально
возможное число фраз, показывает статистику «вы знаете N слов и M фраз» и
проекции «выучите X → узнаете ещё Y фраз» для мотивации.

## Стек

| Слой | Технология |
|---|---|
| Фреймворк | **Nuxt 4** (SSR +Nitro) |
| PWA | `@vite-pwa/nuxt` — service worker, веб-манифест, установка на устройство |
| Стили | **Tailwind CSS 4 + DaisyUI 5** (две кастомные темы: светлая (крем/терракота) и тёмная «графит», oklch) |
| Шаблоны | **Pug** (`<template lang="pug">` в SFC — поддерживается `@vitejs/plugin-vue` из коробки) |
| Язык | **TypeScript** (strict, `bun run typecheck` через `nuxt typecheck`) |
| БД | **SQLite через `node:sqlite`** — без нативных зависимостей (Node ≥ 22) |
| Тесты | **Vitest 5** — два проекта: `unit` (node) и `components` (happy-dom) |

## Возможности

- **318 слов** в 33 уроках: местоимения, 48 глаголов, 110 существительных,
  42 прилагательных, предлоги, наречия, числительные, конструкции +
  урок «Спасательные фразы» (dame, dime, mira, oye, espera — без
  грамматических терминов). Латиноамериканские нормы: только `ustedes`,
  `al/del`, личное `a`, согласование `gustar`.
- **Комбинаторный движок фраз** — 46 шаблонов, **29,1 млн фраз**
  (утверждение / отрицание / да-нет вопросы / вопросительные слова),
  с притяжательными и указательными («Mi padre busca mi teléfono» /
  «Мой папа ищет мой телефон») и маркерами времени «(вообще)»/«(сейчас)»,
  разводящими простое время и estar + герундий.
  Подсчёт аналитический (без перебора), перечисление детерминированное —
  пагинация на странице «Фразы» согласована со счётчиком.
- **Статистика и проекции**: кольца прогресса по частям речи, личный
  счётчик «Ты уже можешь сказать N фраз» и «Повторить сегодня» на главной,
  список «возможностей» с оценкой «выучите «querer» → +N фраз», групповые
  проекции («выучите все предлоги → +Y»).
- **Ключи к шаблонам** — страница «Возможности» и подсказка на «Фразах»
  показывают, какие именно слова откроют пока запертые шаблоны:
  «выучите mi/tu/su/este… (урок 9) → +22 302 фразы».
- **Механика «выучено»** — объективный счётчик: 2 верных ответа на слово.
- **Практика**: тест-выбор, сборка фразы из плиток (цветная по роли слова:
  глаголы красные, существительные синие, предлоги серые — плитки учат
  структуре), аудио с записью своего голоса (сравни с эталоном),
  активный перевод (вспомни и введи слово по-русски), микс. В «Сборке» —
  👍 «нравится» (личная коллекция, фраза показывается чаще) и 👎 «не
  нравится» (фраза больше не показывается), кнопка «Послушать целиком»
  после сборки. Сложный режим «Слова по шагам».
- **Мотивация**: серия дней (streak), 22 достижения — в том числе речевые
  («Сказал 100 фраз», «Собрал фразу без ошибок с первого раза»), графики
  прогресса.
- **Интерфейс RU/ES** с мгновенным переключением, светлые/тёмные темы.
- **Аккаунты + синхронизация**: регистрация по PIN (scrypt + Bearer-токен),
  прогресс хранится в localStorage и синхронизируется с сервером (монотонное
  слияние — слово не может «разучиться» после синка).
- **Оффлайн**: service worker кеширует приложение, прогресс — локально.

## Запуск

```bash
bun install          # или npm install / pnpm install
bun run dev          # http://localhost:3000
```

Продакшен:

```bash
bun run build && bun run preview
```

Пути БД задаётся переменной `NUXT_DB_PATH` (по умолчанию `db/custom.db`).

## Как появляются фразы

Фраза собирается движком, когда **все обязательные слова какого-то шаблона
выучены** (по 2 верных ответа). Поэтому путь по урокам важнее разрозненных
слов — кумулятивно после каждого урока доступно фраз:

| После урока | Слов | Фраз |
|---|---|---|
| 1. Местоимения и ser/estar | 12 | 0 |
| 2. Артикли и количество | 22 | 0 |
| 3. Первые вопросы | 32 | **3** — первые фразы |
| 4. Базовые глаголы | 40 | 724 |
| 6. Ключевые глаголы (tener, ir, poder…) | 57 | 1 236 |
| 8. Семья | 78 | 4 270 |
| 9. Притяжательные и указательные (mi, este…) | 84 | 26 572 |
| 10. Люди и профессии | 92 | 75 511 |
| 26. Наречия II (estar + герундий…) | 254 | 13 438 479 |
| 33. Спасательные фразы (весь словарь) | 318 | **29 091 555** |

Определители-местоимения (урок 9) — самый «дешёвый» большой ключ:
ми/ту/су/эсте добавляют +22 302 фразы разом — определитель умножает
каждую именную ось. Приложение само показывает актуальные ключи
на страницах «Возможности» и «Фразы».

## Архитектура

```
shared/               # изоморфный слой (клиент + сервер)
  types.ts            # доменные типы: Word, VerbData, Progress, KNOWN_THRESHOLD
  data/words/         # словарь: фабрики v()/n()/a()/p()... + 6 файлов по частям речи
  data/lessons.ts     # метаданные 33 уроков
  phrases/
    schema.ts         # Unit (6 типов) / Template / PhraseKind
    engine.ts         # count / gains / enumerate / sample + совместимость детерминаторов
    es.ts, ru.ts,
    ru-morph.ts       # испанская и русская грамматика (артикли, al/del, склонения)
    templates.ts      # 39 шаблонов фраз
  stats.ts            # phraseStats / opportunities / groupOpportunity / progressByPos
  streak.ts, achievements.ts, practice.ts, i18n/
server/
  utils/db.ts         # node:sqlite: profiles / tokens / progress
  utils/auth.ts       # scrypt-PIN, Bearer-токены, валидация
  api/auth/*, api/progress/*, api/health
app/
  layouts/default.vue # шапка, мобильная нижняя навигация, футер
  pages/              # index (дашборд), lessons, words, phrases, practice,
                      # opportunities, achievements, settings
  components/         # 17 Pug-компонентов (WordCard, QuizBuild, StatRing...)
  composables/        # useProgress (синк 800 мс), useAuth, useI18n,
                      # useTheme, useSpeech, useInstall
test/
  unit/               # данные, грамматика, движок, статистика, API, merge
  components/         # рендер компонентов (happy-dom)
```

## Ключевые гарантии (покрыты тестами — 129 шт.)

- `Σ gains == count(расширенное множество) − count(базовое)` — проекции точны.
- Перечисление фраз согласовано со счётчиком шаблона (пагинация не врёт).
- Монотонное слияние прогресса: знание слова не откатывается при синке.
- Русские переводы не содержат служебных заглушек и скобочных пометок.
- API: регистрация → вход → неверный PIN 401 → PUT/GET прогресса →
  запрос без токена 401.
